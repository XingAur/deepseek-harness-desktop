# Project Skills

Skills in this directory ship with the repository and are discovered by DSH
under the `project-agents` source (visible in Settings → Skills).

## Curation policy

Only vendor-neutral, methodology-level skills belong here:

- No company-internal system names, ticket IDs, repository names, or SDK namespaces.
- No credentials, internal hosts, or customer data.
- Concrete business-domain skills stay in each contributor's private skill
  directory (`~/.agents/skills/`) and are never committed.

## Currently shipped

- `requirement-delivery-flow` — evidence-driven workflow for carrying a
  complex requirement from intake to verified delivery (gate-based phase
  control, Requirement Contract state machine, honest evidence
  classification).
